# 30 定位

> 状态：🚧 编写中

本章解决"机器人在已知地图中知道自己在哪"的问题，覆盖 2D 概率定位、多传感器融合与 3D 点云定位三条技术路线。

## 规划小节

- 01 AMCL 原理：粒子滤波、运动/观测模型直观解释
- 02 AMCL 调参实战：粒子数、alpha 系列参数、激光模型参数与常见"定位漂移"处理
- 03 robot_localization EKF 融合：轮式里程计 + IMU 融合配置、协方差设置、odom/map 两级 EKF 架构
- 04 hdl_localization 3D 定位：基于 NDT/GICP 的点云地图定位、初始位姿给定
- 05 定位质量评估：如何判断"定得准不准"（协方差、粒子云形态、TF 抖动）

## 前置条件

完成 [20 2D 建图](../20_2D建图/README.md)（AMCL 需要 2D 地图）；3D 定位需 [25 3D激光SLAM](../25_3D激光SLAM/README.md) 产出的点云地图。
