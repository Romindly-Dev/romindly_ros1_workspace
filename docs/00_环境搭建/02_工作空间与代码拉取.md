# 工作空间创建与代码拉取

## 目标

创建 catkin 工作空间 `~/ws_romindly`，用 vcstool 批量拉取本学习套件的全部仓库，安装依赖并完成首次编译，最后用 URDF 演示验证工作空间可用。

## 背景简述

catkin 是 ROS1 的构建系统。一个 catkin 工作空间包含三个目录：

| 目录 | 作用 |
| --- | --- |
| `src/` | 源码目录，所有功能包（package）放在这里，唯一需要手动管理的目录 |
| `build/` | 编译中间产物（CMake 缓存、目标文件），由 `catkin_make` 自动生成 |
| `devel/` | 编译结果（可执行文件、setup.bash 等），source 它即可使用工作空间内的包 |

本套件由多个 Git 仓库组成，通过一个 `ros1.repos` 清单文件描述。`vcstool` 读取该清单即可一条命令拉齐全部仓库。

## 分步操作

### 1. 创建工作空间目录

```bash
mkdir -p ~/ws_romindly/src
cd ~/ws_romindly
```

### 2. 安装 vcstool 和 git

```bash
sudo apt update
sudo apt install -y git python3-vcstool
```

验证：

```bash
vcs --version
```

预期输出（版本号可能不同）：

```
vcs 0.2.x
```

### 3. 克隆主仓库

```bash
cd ~/ws_romindly
git clone https://github.com/Romindly-Dev/romindly_ros1_workspace.git src/romindly_ros1_workspace
```

> 国内访问 GitHub 慢时，可临时使用镜像加速（如 `https://ghproxy.com/` 前缀），或配置代理。

### 4. 用 vcs 批量拉取全部仓库

主仓库内的 `ros1.repos` 列出了套件全部依赖仓库：

```bash
cd ~/ws_romindly
vcs import src < src/romindly_ros1_workspace/ros1.repos
```

预期输出（每个仓库一行，`.` 表示成功）：

```
=== src/xxx (git) ===
Cloned https://github.com/... to src/xxx
...
```

拉取完成后确认：

```bash
ls ~/ws_romindly/src
```

应能看到 `romindly_ros1_workspace` 及清单中的各个包目录。

### 5. rosdep 安装依赖

```bash
cd ~/ws_romindly
rosdep install --from-paths src --ignore-src -r -y
```

> 国内环境请使用 rosdepc（用法完全相同）：
>
> ```bash
> rosdepc install --from-paths src --ignore-src -r -y
> ```

预期输出（末尾）：

```
#All required rosdeps installed successfully
```

### 6. 编译

```bash
cd ~/ws_romindly
catkin_make
```

首次编译耗时数分钟。预期输出（末尾）：

```
[100%] Built target ...
```

编译完成后工作空间下会新增 `build/` 和 `devel/` 两个目录。

### 7. source 工作空间环境

```bash
source ~/ws_romindly/devel/setup.bash
```

建议写入 `.bashrc`，避免每次手动执行：

```bash
echo "source ~/ws_romindly/devel/setup.bash" >> ~/.bashrc
```

> `devel/setup.bash` 会自动链式加载 `/opt/ros/noetic/setup.bash`，两者写入顺序上确保工作空间的在后即可。

验证包能被找到：

```bash
rospack find urdf_demo
```

预期输出：

```
/home/<用户名>/ws_romindly/src/.../urdf_demo
```

### 8. 验证：启动 URDF 演示

```bash
roslaunch urdf_demo display.launch
```

预期现象：弹出 RViz 窗口，显示一辆蓝色差速小车模型；左侧面板中 RobotModel 状态为 OK。同时会弹出 joint_state_publisher 的滑条窗口，拖动滑条可以看到轮子转动。

按 `Ctrl+C` 退出。至此工作空间搭建完成。

## 常见问题排查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `git clone` 超时 / 速度 KB 级 | GitHub 访问受限 | 使用镜像前缀或代理；`vcs import` 拉取的子仓库同理，可编辑 `ros1.repos` 中的 URL |
| `vcs: command not found` | vcstool 未安装 | `sudo apt install python3-vcstool`（注意包名不是 vcstool） |
| `rosdep install` 部分包报 `Cannot locate rosdep definition` | rosdep 缓存未更新或无国内源 | 执行 `rosdepc update` 后重试；`-r` 参数已允许跳过失败继续 |
| `catkin_make` 报找不到某包（`Could not find a package configuration file`） | 依赖未装全 | 重跑第 5 步；仍缺则按报错包名手动 `sudo apt install ros-noetic-<包名（下划线换连字符）>` |
| `catkin_make` 报 CMake 版本 / 混用错误 | 曾用 catkin build 编译过 | 删除 `build/` 和 `devel/` 后重新 `catkin_make`（两套工具不能混用同一工作空间） |
| `roslaunch` 提示找不到 urdf_demo | 未 source devel/setup.bash | 执行第 7 步，或开新终端（已写入 .bashrc 时） |
| RViz 中模型全白 / 报 No transform | Fixed Frame 不对 | 将 RViz 左上 Fixed Frame 改为 `base_link`（或 launch 文件指定的根坐标系） |
