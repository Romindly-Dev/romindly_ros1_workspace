# 25 3D 激光 SLAM

> 状态：🚧 编写中

本章面向多线激光雷达场景，介绍三种代表性 3D SLAM 方案的原理、部署与在 x86_64 边缘计算单元上的算力评估，帮助选出适合自己硬件的方案。

## 规划小节

- 01 A-LOAM 原理精讲：特征提取（边缘/平面点）、scan-to-scan 里程计、scan-to-map 优化
- 02 A-LOAM 编译运行与公开数据集回放（KITTI / 自录 bag）
- 03 LIO-SAM 实战：IMU 紧耦合、外参与时间同步要求、GTSAM 依赖安装
- 04 FAST-LIO2 实战：ikd-Tree、低算力平台上的表现
- 05 算力评估：三种方案在本套件边缘计算单元上的 CPU/内存占用与实时性实测对比
- 06 选型建议：有无 IMU、雷达线数、算力预算三维度决策表
