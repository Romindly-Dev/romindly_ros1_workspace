Launch Sequence

三分钟部署Deploy in 3 Minutes

已装好 Noetic 的机器上，四步拉起整个舰队。没装 ROS？从 环境搭建第一篇 开始。 Four steps to launch the whole fleet on a machine with Noetic installed. No ROS yet? Start from the first setup tutorial.

iot@edge-unit: ~/ws_romindly 
# 1. 建工作空间，克隆总仓库# 1. Create the workspace, clone the main repo
mkdir -p ~/ws_romindly/src && cd ~/ws_romindly/src
git clone https://github.com/Romindly-Dev/romindly_ros1_workspace.git

# 2. vcstool 一键拉取全部仓库# 2. Pull the whole fleet with vcstool
cd ~/ws_romindly
vcs import src < src/romindly_ros1_workspace/ros1.repos

# 3. 装依赖，编译# 3. Install dependencies, build
rosdep install --from-paths src --ignore-src -r -y
catkin_make

# 4. 点火验证# 4. Ignition check
source devel/setup.bash
roslaunch urdf_demo display.launch
# ✓ RViz 弹出蓝色差速小车 —— 舰队就绪# ✓ RViz shows the blue diff-drive robot — fleet ready
